# Visual Recipe｜视觉配方工厂：项目任务书

## 产品承诺

把用户上传的参考图拆成一份可解释、可编辑的视觉配方，再将这份配方保存为工作流，批量应用到多件静物商品，并自动拦截商品变形和风格跑偏的结果。

## 核心用户

- 核心：需要把同一视觉方案批量应用到多个SKU的小型电商运营或设计团队。
- 辅助：需要拆解参考图、调试视觉规则的电商设计师。
- 首版不服务：服装换装、人物写真、复杂包装文字、通用设计工作流用户。

## 核心矛盾

同一参考风格批量用于不同商品时，如何既保持风格，又不让商品“变脸”。

## 核心闭环

`参考图 → 视觉配方 → 商品身份锁定 → 场景图生成 → 双重验收 → 定向修复 → 批量导出`

## 首版范围

- 商品类型：静物商品，优先陶瓷杯、花瓶、香薰器或桌面摆件。
- 结果类型：每件商品生成一张场景图。
- 批量规模：最多5件商品，每件2至3张身份照片。
- 工作流：一条固定主干、有限节点的半开放工作流。
- 模型：Seed-2.1-pro-0915负责视觉理解、规划和验收；一个图片模型负责生成。
- 使用方式：无Key预置案例、用户自带Key、自部署。

## 模型角色

- 豆包工作：项目初始化、代码开发、测试和长程交付工具。
- Seed-2.1-pro-0915：参考图解析、商品身份识别、视觉配方规划、结果验收和修复建议。
- 图片模型：被工作流调用的生成工具，不是文章主角。
- 代码规则：校验Schema、文件、比例、任务状态和确定性约束。

## 不做清单

首版不做登录、云同步、支付、积分、会员、多人协作、模特工厂、AI换装、Logo生成、视频生成、模板市场、任意自定义代码、多模型供应商、平台图片抓取、去水印和任意拓扑画布。

## 成功定义

1. 一条真实视觉工作流可以在画布保存，并在批量页调用。
2. 5件静物商品共用同一配方，每件生成一张场景图。
3. 商品身份和视觉配方分别验收。
4. 单商品失败不会拖垮整个批次。
5. 至少保留一次真实失败、判断、修复和前后对比。
6. 预置案例无需Key即可完整浏览，且所有结果来自真实保存的运行。
7. 完成A/B/C对照、隐藏错误集、盲评、真实测试、构建、Demo和录屏。

## 降级产品

若图片生成在停止线前仍不稳定，产品降级为“视觉配方提取与批量验收台”：保留参考图解析、商品身份锁定、批量检查、问题定位和修复建议；生成节点作为可选能力，不伪装稳定。
