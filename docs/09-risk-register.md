# 产品风险登记与停止线

| 风险 | 早期信号 | 预防 | 触发后的处理 |
|---|---|---|---|
| 范围膨胀 | 新增图片类型、节点、账号或模型 | 不做清单与功能冻结 | 全部移入赛后路线图 |
| 配方输出不稳定 | 连续出现缺字段或Schema失败 | 先做3次探针 | 停止画布开发，修模型合同 |
| 身份特征幻觉 | 推测被当成硬约束 | 用户确认闸门 | 改为更多人工锁定 |
| 图片生成不稳定 | 两天仍无法完成主流程 | 单模型、单场景图 | 降级为分析与验收台 |
| 画布吞噬工期 | 占用超过总工期25% | 固定主干与7节点 | 改为固定流程可视化 |
| 批量状态丢失 | 刷新后任务无法判断 | IndexedDB和显式interrupted | 上限降为3件并简化恢复 |
| 用户额度失控 | 自动运行和反复修复 | 运行前预算、修复最多一次 | 暂停整批并要求确认 |
| Key泄漏 | 出现在日志、URL或持久存储 | sessionStorage、脱敏测试 | 阻止发布，轮换测试Key |
| SSRF或代理滥用 | 用户可传任意URL | 固定域名与服务端白名单 | 阻止发布并修复 |
| 素材权利不明 | 演示图来自未知平台 | 自摄或授权素材 | 更换素材，不投稿该案例 |
| 模型自评偏差 | 生成与验收结论过于一致 | 代码规则、隐藏错误、盲评 | 缩小主张并公开误报漏报 |
| 文章证据不足 | 只有最好截图 | 从首轮保存全部结果 | 停止加功能，优先补实验 |

## 强制停止线

- 配方探针或身份探针未通过：不得开发完整画布。
- 生成接口连续两天不稳定：启用降级方案。
- 正式实验开始后：禁止新增功能。
- 发布条件任一失败：不得公开实时模式，只发布只读案例。
- 素材授权无法确认：不得使用该素材做Demo或文章证据。

## 功能冻结

- 投稿前4天冻结功能。
- 前3天只修主流程和数据问题。
- 前2天完成正式实验、截图和录屏。
- 前1天只处理文章、链接、复现与投稿检查。
