# 分阶段验收矩阵

## 阶段0：素材准备

- 选定一件真实静物商品作为探针样本。
- 获得2至3张多角度照片。
- 获得1至5张有权使用的参考图。
- 人工写出身份特征和配方金标准。

## 阶段1：模型探针台

- 同一参考组连续3次输出均通过VisualRecipe Schema。
- 12个核心字段无大面积缺失。
- 推测不被标记为事实。
- 5张明显错误图至少识别4张。
- Key安全检查、类型检查、测试和构建通过。

未通过则不得进入阶段2。

## 阶段2：单件工作流

- 视觉配方经用户确认。
- 商品身份候选经用户确认。
- Prompt由结构化配方编译。
- 一件商品真实生成场景图。
- 验收状态、证据和问题可查看。
- 失败结果可以定向修复一次并保留前后版本。

## 阶段3：画布与批量

- 画布与批量页使用同一WorkflowDefinition。
- 5件商品可分组、排队、暂停、恢复和隔离失败。
- 刷新后状态不会被伪装为仍在运行。
- 开始前展示最大调用次数。
- 单商品失败不影响其余商品。

## 阶段4：正式实验

- 完成至少18张A/B/C结果，目标30张。
- 完成10张隐藏错误测试。
- 完成2名外部人员盲评。
- 汇总首次通过率、修复率、误报漏报、耗时、Token和调用数。
- 保留全部失败，不只展示最佳样本。

## 阶段5：发布与投稿

- 无Key预置案例完整可浏览。
- 公共代理固定允许域名且无敏感日志。
- 非法输出、失败恢复和刷新场景通过测试。
- 桌面主流程和移动端报告可用。
- 生产构建、在线Demo、仓库、录屏和复现说明齐全。
- 文章数字与真实证据逐项核对。

只有当前阶段全部通过，才允许进入下一阶段；例外必须记录原因、风险和缩小后的主张。
