# 12 · 画布工作台规格（Canvas Workspace）

状态：本文件在自定义工作流阶段被**重写**。
旧版“节点固定、连接只读、不可增删节点”的规定已废止，以 docs/15 的可执行自定义图为准。
本文定义画布的布局、交互与可视化；图的数据模型与执行见 docs/15。

---

## 1. 产品定义

画布既是**工作流编辑器**，也是**可执行控制台**：
- 编辑：添加、删除、复制节点，连接有类型端口，保存草稿，发布不可变版本；
- 执行：对单件试运行，或发布后供批量调用；
- 可信：画布呈现的每个节点状态都来自真实执行（或明确的“未运行”），不播放模拟动画。

## 2. 专注式页面结构（取代旧五栏常显布局）

进入项目默认打开画布。采用**专注模式**，尽量把横向空间让给画布：

```text
┌──────────────────────────────────────────────────────────────┐
│ 56 顶栏（精简）：←项目 · 工作流名/版本 · 保存态 · 运行 ▾ · 模型状态 · 更多 │
├──────┬───────────────────────────────────────────────────────┤
│ 56   │ 浮动工具条（缩放/适应/撤销重做/节点库开关/检查器开关）          │
│ 收窄 │                                                        │
│ 主导 │                  无限画布（节点 + 有类型连线）              │
│ 航轨 │                                                        │
│      │              ┌─ 节点检查器（覆盖抽屉，默认关闭）─┐          │
│      │              │ 仅点击节点时从右侧覆盖出现          │          │
│      │              └───────────────────────────────┘          │
├──────┴───────────────────────────────────────────────────────┤
│ 42 运行抽屉（默认折叠为一行，点开 280）                            │
└──────────────────────────────────────────────────────────────┘
```

- **全局导航收窄为 56px 图标轨**（工作台/批量/素材/记录/设置，仅图标+tooltip；可临时展开到 208px，但不持久抢占）。
- **节点库默认收起**：通过浮动工具条按钮或从节点尾部“+”呼起，以**浮层面板**或**命令式插入菜单**出现，选中类型后即在画布落点插入；不常驻占栏。
- **右侧检查器默认关闭**：不点击节点时画布无右栏；点击节点，检查器以**覆盖抽屉**（不推挤画布网格）滑出；点击空白或按 Esc 关闭。
- **运行抽屉默认折叠**：一行显示当前步骤/调用数，展开后 280px 显示时间线、预算、版本（docs/15 §执行）。

docs/13 的几何令牌相应调整：`--sidenav-w: 56px`（专注默认）、`--sidenav-w-expanded: 208px`；节点库不再有常驻宽度变量。

## 3. 顶部工具栏（专注态）

从左到右：返回项目、工作流名（可重命名）+ 版本徽标（草稿 / 已发布 vN）、保存状态（保存中·已保存·保存失败）；
右侧：**运行 ▾**（主操作；含“试运行此件”“发布为新版本”）、模型状态灯、更多（切到批量、键盘快捷键说明）。

“发布”与“运行”分离：草稿未通过校验时“发布”禁用并提示首个错误；无 Key 时“运行”禁用，“发布/保存/编辑”可用。

## 4. 节点

### 4.1 结构
节点卡片宽度 248–280px：
- 头部：类型图标、标题、运行状态点；
- 端口：左侧入端口、右侧出端口（小圆点，按数据类型着色）；
- 摘要区：1–2 行关键信息（数量/置信/分数/版本），细节进检查器；
- 人审闸门节点带显著“待确认”把手。

### 4.2 操作
- **单击**：选中并打开覆盖检查器；**双击空白**：在该位置打开插入菜单；
- **拖动节点头部**：移动；**Delete/Backspace**：删除选中（source/sink 等不可删节点禁用删除并解释）；
- **复制**（Ctrl/Cmd+D 或右键）：深拷贝节点与配置，生成新 id，**不复制连线**（避免非法接线），偏移 24px；
- 节点上的“+”尾端按钮：从该节点兼容的输出类型快速追加下一节点。
- 运行中或已被已发布版本引用的节点仍可在**草稿**里编辑，但不影响历史版本。

### 4.3 节点状态（真实执行派生）
统一状态不变：`未配置 / 等待 / 运行中 / 待确认 / 已完成 / 警告 / 失败 / 已跳过`。
自定义图下状态按**执行计划中该步骤的最近一次结果**派生；未被本次运行触达的节点显示“未运行”，不得显示成成功。

## 5. 连线（有类型、可编辑、受校验）

- 从输出端口拖到输入端口建立连线；拖拽中实时高亮**类型兼容**的端口，不兼容端口禁用并在松手时提示原因（docs/15 §5.4）。
- 端口类型用颜色+形状+悬浮类型名三重表达（docs/13：颜色不作为唯一信号）。
- 单源入端口已有入边时，再接入则替换旧边并二次确认；集合型图片端口可多源。
- 点击连线选中（高亮），Delete 删除。
- “仅验收失败时”的修复边用虚线+条件标注；它在执行计划中编译为条件重生，不构成图中环。
- 试图制造环时连线不成立，提示“工作流不能包含循环”。

## 6. 画布视口交互

- 空白拖动平移；滚轮以指针为锚点缩放，范围 0.2–2.5；
- 工具条：放大、缩小、百分比、100%、适应全部节点；
- 小地图（可关）：节点缩略与当前视口框；
- 键盘：方向键移动选中节点（Shift 加速）、Esc 关检查器/取消连线、`[` 收主导航、`/` 聚焦插入菜单、Ctrl+F 适应；
- 自动布局（dagre 风格分层）作为**一键整理**提供，不强制，用户位置优先；
- pan/zoom/节点位置/连线拐点按项目+草稿 800ms 防抖自动保存，刷新恢复；业务进行中刷新，进行中节点判为 interrupted（不伪装运行）。

## 7. 右侧检查器（覆盖抽屉）

- 宽 340–400px，绝对覆盖在画布右侧，带遮罩可点空白关闭；Esc 同效。
- 内容随节点类型变化：source=上传与用途；analysis=模型摘要+证据+运行；gate=逐条确认/驳回+风险说明；transform=只读编译 Prompt 与来源映射；generation=参数+预算+运行；audit=四维分+问题+证据；repair=受限 Patch+高风险确认；sink=版本对比+接受/下载。
- 检查器区分**草稿配置**与**已确认事实**：已确认的配方/身份字段在检查器只读，修改需走新版本。
- 技术详情（诊断、原始响应、requestId）折叠在“技术详情”内。

## 8. 运行抽屉

折叠态一行：当前步骤、状态、`已用 / 预计（最坏）`、无 Key 说明。
展开：节点时间线（按计划步骤，而非固定 7 步）、调用预算（由计划 model-call 数推导）、版本与产物（V1/V2、验收分、修复记录）、暂停/终止（仅已配置）。
人工闸门到达时：抽屉与对应节点同时提示待确认，并自动定位/选中该节点打开检查器，用户在检查器内完成确认后继续。

## 9. 草稿与版本在画布上的表达

- 画布标题徽标：`草稿（未发布）`、`vN（已发布）· 有未发布改动`；
- 未通过校验的节点/端口有错误描边，顶部“发布”按钮给出错误计数，点击逐项定位；
- 发布成功后画布切换为查看该版本（只读高亮），“编辑新版本”再回到草稿；
- 版本差异视图：新增/删除节点、改配、改线分别着色。

## 10. 无 Key 与只读

- 未配置模型：完整编辑器、节点库、校验、发布全部可用；模型类节点“运行”禁用并提供唯一“配置模型”入口；不出现整页门禁遮挡。
- 从运行记录回看某次执行时：画布以该执行所用版本只读呈现（节点位置+结果叠加），不可编辑。

## 11. 响应式与可访问性

- ≥1280：专注三浮动层布局；1024–1280：导航固定 56，检查器全宽覆盖；<1024：画布只读审阅优先，编辑操作收敛到“更多/平板不承诺完整编辑”，手机端只保证查看结果与审批。
- 全部交互可键盘到达；焦点环可见；端口/状态不只靠颜色；动效遵循 `prefers-reduced-motion`（连线不做高强度流动动画，仅当前步骤轻呼吸）。
