# Visual Director UI 设计系统

## 1. 设计方向

设计概念为“数字摄影工作台”：精密、安静、高信息密度，以商品图像和可追溯工作流为主角。避免普通管理后台、暗色霓虹 AI 工具、大面积渐变和玻璃拟态。

产品唯一需要突出的视觉签名是“视觉依据轨道”：从参考图、配方字段、身份约束、Prompt 到结果验收均能看到来源关系。除此之外保持克制。

## 2. 色彩令牌

| 角色 | 色值 | 用途 |
|---|---|---|
| Canvas Mist | `#EEF1F0` | 画布和应用背景 |
| Panel White | `#FAFBFA` | 面板背景 |
| Surface | `#FFFFFF` | 节点、卡片、输入控件 |
| Ink | `#17201D` | 主文字 |
| Muted Ink | `#697671` | 次级文字 |
| Director Green | `#176B57` | 品牌与主操作 |
| Signal Teal | `#2F8F75` | 运行中、连线、焦点 |
| Review Amber | `#C88324` | 待确认与警告 |
| Failure Red | `#C44B44` | 失败和危险操作 |
| Hairline | `#D7DFDC` | 边框和分隔线 |

颜色不能成为唯一状态信号，必须同时提供图标和文字。

## 3. 字体

- 中文界面：`MiSans, "Noto Sans SC", "Microsoft YaHei", sans-serif`。
- 英文与数字：`Inter, Arial, sans-serif`。
- Prompt、运行编号和技术信息：`"JetBrains Mono", Consolas, monospace`。
- 页面标题 24–32px；面板标题 16–18px；正文 14px；辅助信息 12px；禁止大面积 10px 小字。

## 4. 密度与空间

- 基础间距单位 4px，常用间距 8/12/16/24/32px。
- 面板圆角 10–12px，节点圆角 10px，按钮圆角 7–8px。
- 阴影仅用于浮层、选中节点和悬浮元素；普通卡片主要依靠边框分层。
- 表格行高至少 44px，按钮高度至少 36px，主要按钮 40px。
- 内容最大宽度只用于项目首页；工作台和数据页面使用全宽布局。

## 5. 组件规范

### 按钮

- 一个区域最多一个主按钮。
- 危险操作使用红色文字或边框，最终删除需二次确认。
- 图标按钮必须有可访问名称和 Tooltip。

### 卡片

卡片只用于表达一个可独立理解的对象。禁止为了视觉效果给每一层内容都套卡片，避免“卡片套卡片”。

### 表单

标签始终可见，不只依赖 placeholder。错误紧邻字段，说明修复方法。模型技术参数与普通业务参数分组展示。

### 图片

图片是产品主内容。缩略图比例统一，加载时保留尺寸；提供放大查看、来源、版本、尺寸和状态。不得用过小缩略图掩盖真实生成质量。

### 状态与反馈

Toast 只用于短暂成功反馈；需要用户处理的错误必须保留在页面中。长任务显示当前步骤和可取消状态，不使用无限旋转图标作为唯一反馈。

## 6. 动效

- 面板开合 160–220ms。
- 节点选中、拖动和连线使用轻量过渡。
- 工作流运行仅突出当前节点，不让所有连线同时运动。
- 禁止循环漂浮、背景粒子和与任务无关的入场动画。
- 完整支持 `prefers-reduced-motion`。

## 7. 响应式与可访问性

- 1440×900 为主要设计基准；1280×720 必须可用。
- 1024px 以下默认折叠左导航，右侧检查器可覆盖打开。
- 手机端提供项目、运行记录、结果查看和审批，不承担复杂画布编辑。
- 所有交互支持键盘焦点；正文与背景对比度至少 WCAG AA；触摸目标不小于 40px。

## 8. 禁止项

- 不使用“阶段1/阶段2”“探针台”等开发文案作为产品标题。
- 不使用无意义的大数字仪表盘。
- 不使用紫蓝渐变、霓虹边框、光晕球作为 AI 身份符号。
- 不把五个以上主要按钮排列在同一视觉层级。
- 不在同一页面混用多套圆角、阴影和状态颜色。
- 不用占满首屏的大型空状态隐藏真实产品结构。

## 9. 专注式画布几何（自定义工作流阶段）

配合 docs/12 的专注布局，几何令牌更新为：

| 令牌 | 值 | 用途 |
|---|---|---|
| `--sidenav-w` | 56px | 画布内收窄主导航轨（仅图标） |
| `--sidenav-w-expanded` | 208px | 临时展开（hover/钉选，不持久抢占） |
| `--topbar-h` | 56px | 不变 |
| `--drawer-h-collapsed` | 42px | 运行抽屉折叠 |
| `--drawer-h` | 280px | 运行抽屉展开 |
| `--inspector-overlay-w` | 340–400px | 覆盖式节点检查器（绝对定位，不推挤画布） |
| `--nodelib-popover-w` | 240px | 节点库浮层/插入菜单（非常驻栏） |
| 节点宽 | 248–280px | 卡片摘要，不塞完整表单 |
| 端口直径 | 12px | 有类型端口圆点，命中区不小于 24px |

节点库与检查器从“常驻栅格列”改为“按需浮层/覆盖抽屉”，画布在无人操作时占满主导航右侧全部空间。

## 10. 统一组件原语（跨官网/项目页/画布/批量/记录/设置）

新增自定义工作流阶段需要并应复用的原语（命名建议，避免每页各造一套）：

- **Button**：`primary / default / ghost / danger`，尺寸 `sm(28) / md(36) / lg(40 主按钮)`；一区域一个 primary。
- **IconButton**：36×36，带 `aria-label` 与 tooltip；画布工具条只用它。
- **TextInput / TextArea / Select / Checkbox / RadioCard**：标签常显、错误紧邻、焦点环 2px Signal Teal。
- **Card**：单层 1px Hairline + 12px 圆角；禁止卡片套卡片；官网特性、项目卡片、检查器分组、设置分组共用。
- **Badge / StatusDot / StatusBadge**：状态语义色固定（通过=绿、待确认=琥珀、失败=红、运行=Signal Teal、跳过=灰），状态同时有图标和文字，不仅靠颜色。
- **Tabs / SegmentedControl**：仅用于同对象视图切换，不用于一级导航。
- **Toolbar**：画布浮动工具条（缩放/适应/撤销重做/库与检查器开关）；分组用细分隔线，不放主 CTA。
- **Drawer（覆盖抽屉）**：右侧覆盖、含头部标题与关闭、Esc/点遮罩关闭；节点检查器、批量单件详情统一用它，不再新造弹窗形态。
- **Modal**：仅用于阻断式确认（发布确认、删除、风险确认）与模型设置。
- **DataTable**：批量任务与运行记录共用（行高≥44、表头 Hairline、状态用 StatusBadge、行内操作为 IconButton+文字）。
- **Toast / InlineError / EmptyState / LoadingBlock / SaveStateText**：按 docs/11 §6 的状态集一一对应；错误可持久、成功用 Toast。
- **Port / Edge / NodeCard / InsertMenu / ValidationPopover / VersionBadge / DiffView**：画布专属原语，状态取色仍走全局语义令牌。

所有原语只使用 §2 的色板与 §3 的字阶/圆角/间距；新增颜色必须先补令牌，不允许页面内硬编码。
