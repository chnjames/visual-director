# 14 · UI 验收矩阵

每项列出可观察、可测试的验收条目。仅当全部通过才宣布阶段完成；不接受"截图好看"作为单独完成依据。
本矩阵在自定义工作流阶段更新：新增官网、可编辑可执行图、专注布局、草稿/版本四组条目；
原 §4 中“固定节点/只读连线”相关条目由本文件“工作流图与版本”组取代。

## 1. 全局结构

- [ ] `/` 为公开官网，无需 Key/项目可完整阅读，CTA 能到 `/projects`。
- [ ] `/projects` 为项目首页；项目内导航包含工作台、批量任务、素材库、运行记录、设置。
- [ ] 进入项目默认进入画布；画布中主导航收窄为 56px 图标轨。
- [ ] 探针（配方/身份/验收）没有一级或平级产品入口，只作为节点与检查器存在。
- [ ] 产品标题、节点与页面不出现“阶段 N / 探针台”等开发文案。

## 2. 项目首页

- [ ] 可创建项目并打开；卡片显示状态、版本号、生成数、待确认数与修改时间。
- [ ] 搜索、排序、状态筛选具有可理解的反馈（数量变化/空结果）。
- [ ] 空状态有明确下一步（新建/从标准模板新建），不占满首屏。
- [ ] 无 Key 仍可创建项目、进入画布、编辑与发布（运行禁用）。

## 3. App Shell 与专注布局

- [ ] 固定视口：顶栏 56，画布主区与运行抽屉各自独立滚动，整页不出现长滚动。
- [ ] 画布默认：主导航 56、节点库收起、右侧无检查器、运行抽屉折叠为 42 一行。
- [ ] 节点库按需浮层打开；选择类型后在落点插入节点，可关闭。
- [ ] 点击节点：右侧以覆盖抽屉（不推挤画布网格）打开检查器；点空白或按 Esc 关闭。
- [ ] 运行抽屉展开 280，画布区域相应收缩；折叠恢复。
- [ ] 1440×900 为主要基准无遮挡；1280×720 全部主操作可达；1024 以下检查器全宽覆盖。

## 4. 工作流图与版本（取代旧“固定画布”条目）

- [ ] 可从节点库/插入菜单添加内置节点；可删除（不可删节点被禁用并解释）、复制（不复制连线）。
- [ ] 从输出端口拖到输入端口连线；连线时只高亮类型兼容端口，不兼容不能连并给原因。
- [ ] 单源入端口唯一；试图制造环时连线不成立并提示“工作流不能包含循环”。
- [ ] 修复条件边以虚线显示“仅失败时”，不构成图环。
- [ ] 草稿可随时保存（允许带错）；错误在节点/端口与发布按钮处可见、可逐项定位。
- [ ] 存在任何 error 时不能发布；warning（如无身份硬约束、无验收）需勾选知情。
- [ ] 发布生成不可变版本（vN + checksum），版本可在批量中被选择；草稿不能用于批量。
- [ ] 再次编辑产生新版本，历史版本与其运行可只读回看；可把历史版本复制为新草稿。
- [ ] 标准模板与旧固定主干的节点/闸门/调用次序一致（黄金用例）。
- [ ] 不存在“可点击但无行为”的假连接/假节点；无自定义代码、任意 HTTP、循环入口。

## 5. 画布交互与执行可信

- [ ] 节点支持选择、拖动；空白平移、滚轮以指针缩放 0.2–2.5；100%、适应全部可用。
- [ ] pan/zoom/节点位置按草稿防抖保存，刷新后恢复视口与选中。
- [ ] 8 种节点状态（未配置/等待/运行中/待确认/完成/警告/失败/跳过）只来自真实执行；未触达节点不显示成功。
- [ ] 运行中刷新：进行中节点变为“已中断”，不伪装运行、不自动续跑。
- [ ] 人工闸门到达时自动定位节点并打开检查器；确认后继续，跳过必须有风险确认。
- [ ] 配方未确认不能连到 Prompt 编译/生成（连接级强制，不仅是按钮禁用）。
- [ ] 运行抽屉时间线按执行计划步骤；预算由计划的模型调用数推导（标准模板仍 4/7）。

## 6. 配方、身份、生成、验收、修复（迁入节点后）

- [ ] 配方节点检查器显示 12 字段、置信度、证据与三组约束，确认动作清晰。
- [ ] 身份候选可逐条确认/驳回；仅确认项进入硬约束；跳过有风险提示。
- [ ] Prompt 检查器只读展示编译结果与来源映射，不能反向改写已确认结构。
- [ ] 生成参数、预算、无图片 Endpoint 的错误提示完整。
- [ ] 验收显示四维分、一票否决、问题与证据；warning/needs-review 可人工接受。
- [ ] 高风险修复必须人工确认；每件最多一次；修复不能改已确认配方/身份。

## 7. 批量、素材、运行记录

- [ ] 批量先选已发布版本；显示版本、进度、各状态计数、当前节点、暂停/继续/仅重试失败。
- [ ] 单件失败不阻塞其余；系统级错误整批暂停并有可执行恢复指引。
- [ ] 素材库按类型/来源/尺寸/时间筛选，详情显示使用位置（版本/运行）。
- [ ] 运行记录以一次执行为单位，带版本号、计划时间线、V1/V2、诊断与可复现参数。

## 8. 公开官网 `/`

- [ ] 含定位、痛点价值、6 项功能、适用场景、4 步流程、可定制说明、BYOK/隐私、FAQ、底部 CTA。
- [ ] 明确静物边界与“生成结果需人工核验”，无“一键爆款/100%还原”承诺。
- [ ] 无伪造客户/证言/成绩；示例标注“结构示意，非真实生成结果”。
- [ ] 无外链字体/追踪脚本；移动端单列、键盘可达、对比度 AA。

## 9. 设置与安全表达

- [ ] 设置按项目 / 模型连接 / 生成默认值分组；无项目时只有模型连接。
- [ ] 顶栏「更多」与侧栏都进入同一设置页；状态灯定位到模型连接。
- [ ] API Key 不明文常驻显示；说明仅 sessionStorage、不进项目/URL/日志/导出，且对所有项目共用。
- [ ] 说明本地代理主机白名单、仅内联图片、模型输出经 Schema 校验。
- [ ] 未配置模型时不承诺免费额度；画布编辑/校验/发布不被禁用。

## 10. 工程验证

- [ ] `npm run typecheck` 通过。
- [ ] `npm test` 全部通过，不忽略既有失败；新增图校验（类型/多源/环/不可达/闸门绕过）有纯函数单测。
- [ ] 非法工作流（类型不符、环、未确认配方接生成、修复>1）均被测试拒绝。
- [ ] `npm run build` 通过；浏览器控制台无应用异常。
- [ ] 既有模型合同、状态机、代理安全测试不被弱化；执行仍只经既有 runners。
- [ ] 数据迁移（v3→v4）幂等，旧项目可打开，回退不损坏旧数据。

## 11. 视觉一致性

- [ ] 所有页面使用 §13/§2 令牌，无两套圆角/阴影/状态色。
- [ ] 无卡片套卡片、无紫蓝霓虹、无 5 个以上同级主按钮。
- [ ] 键盘焦点可见；状态有图标+文字；reduced-motion 下无呼吸/流动动画。
- [ ] 任何旧版顶部 Tab + 单列长表单页面仍残留则视为本项不通过。

## 12. 必交截图（自定义工作流阶段）

- [ ] 官网桌面与移动端。
- [ ] 项目首页（有项目与空状态各一）。
- [ ] 专注画布：无 Key 默认态（56 导航、库收起、无检查器、抽屉折叠）。
- [ ] 自定义编辑态：节点库浮层 + 增删/连线中（含一次“不兼容端口”提示）。
- [ ] 节点检查器覆盖抽屉（配方确认节点）。
- [ ] 校验报错与发布确认；版本徽标/差异视图。
- [ ] 运行抽屉展开、等待人工确认画布。
- [ ] 批量选版本页、运行记录详情。
