# 16 · 公开产品官网（Marketing / Landing）

状态：新增。定义公开首页 `/` 的信息结构、文案口径与视觉边界。
视觉令牌沿用 docs/13；官网是**解释与入口**，不含模型调试、不需要 Key。
参考成熟电商视觉产品（如 SellerPic 类）的信息表达节奏，但**不得复制其品牌、文案、截图或任何视觉资产**。

---

## 1. 目标与非目标

目标：
- 首次访问者在 30 秒内理解：这是什么、解决什么问题、为什么可信（可解释 + 人工确认 + BYOK/隐私）、如何开始。
- 提供唯一主 CTA：进入工作台。

非目标：
- 不做账号/登录/支付/套餐页（本机 BYOK 产品）。
- 不做在线试用跑模型（试用在工作台内、用用户自己的 Key）。
- 不伪造客户 Logo、客户证言、生成前后对比“成绩”。没有真实运行前，案例区只放**结构性示意**并明确标注。

## 2. 信息结构（单页纵向 + 锚点）

顺序（自上而下）：

1. **顶部导航**：品牌名、锚点（功能/适用场景/流程/安全与隐私/常见问题）、右侧“进入工作台”按钮。
2. **Hero**：一句话定位 + 一行补充 + 两个 CTA（主：进入工作台；次：查看工作流程）。右侧/下方为产品画布的**静态结构示意**（节点流，不播放假动画、不显示假分数）。
3. **痛点 → 价值**：3 张卡（批量出图风格不一致 / 商品被改形换件 / 黑盒无法追溯），对应（可复用视觉配方 / 商品身份锁定与四维验收 / 每步证据与人工闸门）。
4. **核心功能**：6 个能力块——参考图与视觉配方、商品身份锁定、结构化 Prompt 编译、场景生成、四维验收、定向修复。每块一句话价值 + 要点，不堆术语。
5. **适用场景**：静物电商主图、详情页场景图、一组商品批量出图；明确边界（首版面向静物：陶瓷/花瓶/香薰/摆件等，不做人像换装/复杂包装文字）。
6. **使用流程**：4 步（上传参考图与商品图 → 确认配方与身份两道闸门 → 单件试运行看证据 → 选用已发布版本批量出图）。与工作台术语完全一致。
7. **工作流可定制**（新能力说明）：可在画布增删连接节点、保存草稿、发布版本、批量调用已发布版本；强调“无代码节点、无任意联网、无循环”。
8. **案例/示例**：在没有真实保存运行前，显示“示例工作流导览”占位（只读结构 + 字段说明），**明确标注“结构示意，非真实生成结果”**；有真实运行后，可由用户选择是否把自己的结果作为本地示例（数据不出本机）。
9. **BYOK 与隐私**：自带火山方舟 Key；Key 仅存当前标签页会话；经本地同源代理、主机白名单、只接受内联图片；项目数据存本机浏览器；不提供云端存储。
10. **常见问题**：是否要写代码、能否自由联网/抓取、支持哪些商品、批量上限、失败如何隔离、数据在哪。
11. **底部 CTA + 页脚**：再次“进入工作台”；版本/本地产品说明/免责（生成结果需人工核验，阈值为产品规则非行业标准）。

## 3. 文案口径

- 只承诺静物场景图；不承诺“一键生成爆款”“100% 还原”。
- 区分“视觉配方（商品无关、可迁移）”与“商品身份（不可改变）”。
- 强调人工确认：模型建议，用户决定；高风险修复必须确认。
- 不出现“阶段 N / 探针 / probe / schema / 状态机”等内部词。
- CTA 动词全局统一：进入工作台、新建项目、运行工作流、发布版本。

## 4. 视觉与组件

- 沿用 docs/13 令牌（Canvas Mist 底、Director Green 主色、克制留白、无紫蓝霓虹、无渐变球）。
- 内容最大宽 1120–1200，纵向自然滚动；顶部导航透明→细发丝底边。
- 复用统一组件：Button（主/次/幽灵）、Card（单层边框，不嵌套卡片）、Badge/StatusBadge、特性图标（线性单色）。
- Hero 的画布示意用静态节点/连线组件渲染，状态点仅用中性与品牌色；不使用流动连线动画（reduced-motion 与克制原则）。
- 响应式：≥1280 多列；768–1280 两列；<768 单列、CTA 全宽。

## 5. 路由与实现边界

- `/`（hash 下 `#/`）渲染官网；`/projects` 渲染工作台，互不嵌套。
- 官网为纯静态前端（无新依赖、无后端、无追踪脚本、无外链字体）。
- 官网不读取也不展示项目数据；“进入工作台”清空营销语境直达项目首页。

## 6. 验收要点（并入 docs/14）

- 无 Key、无项目时官网完整可读；所有 CTA 可到达 `/projects`。
- 无伪造客户/成绩；示例区标注“结构示意”。
- 锚点导航、移动端单列、键盘可达、对比度与 reduced-motion 合规。
